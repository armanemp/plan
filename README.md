# PLAN — Daily Trading Brief

وب‌سایت استاتیک، فارسی و راست‌چین برای نگهداری و مطالعهٔ پلن روزانهٔ بازار. بدون سرور، API، فریم‌ورک، پکیج یا وابستگی خارجی.

## شروع سریع

- برای مطالعهٔ آفلاین، مخزن را دانلود یا Clone کن و فایل `index.html` را مستقیماً با مرورگر باز کن.
- اطلاعات هر روز را طبق الگوی `docs/DAILY-PLAN-SPEC.md` در آرایهٔ `plans` داخل `data/plans.js` ثبت کن.
- برای انتشار عمومی، مخزن را از **Settings → Pages → Deploy from a branch → main → /(root)** منتشر کن. انتشار GitHub Pages نیاز به فعال‌سازی در تنظیمات دارد.

## اصول غیرقابل‌مذاکره

- یک رکورد برای هر روز؛ پلن روزهای گذشته را پاک یا با روز جدید جایگزین نکن.
- هر عدد قیمت، زمان خبر، سطح، حد ضرر و هدف باید دستی بررسی و منبع آن مشخص شود.
- وضعیت `draft` یعنی پیش‌نویس و وضعیت `ready` فقط پس از تکمیل چک‌لیست کیفیت.
- سناریو شرطی است، نه پیش‌بینی قطعی یا توصیهٔ تضمین‌شده. «عدم معامله» نیز باید سناریوی معتبر باشد.
- همهٔ زمان‌ها بر اساس منطقهٔ زمانی `Asia/Baku` وارد شوند.
- پروژه خودکار معامله نمی‌کند و دادهٔ بازار را از API دریافت نمی‌کند؛ تحلیل‌ها باید با منبع معتبر به‌روز شوند.

## نگهداری

قالب و توضیحات کامل فیلدها در `docs/DAILY-PLAN-SPEC.md` است. روند آماده‌سازی، کنترل نهایی و بایگانی را در `docs/DAILY-WORKFLOW.md` ببین.
