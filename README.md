# PLAN — میز حرفه‌ای تحلیل بازار

PLAN یک وب‌اپ استاتیک فارسی/RTL برای خواندن پلن روزانه، مرور نمودار و سطوح، مدیریت سناریو، کنترل ریسک، تقویم اقتصادی و ژورنال شخصی است. رابط با HTML/CSS/JavaScript ساده ساخته شده تا بدون فرایند build روی هاست استاتیک منتشر شود.

## امکانات فعلی

- داشبورد واکنش‌گرا با ناوبری دسکتاپ، منوی موبایل و نوار دسترسی سریع پایین صفحه
- پوستهٔ تیره/روشن با ذخیرهٔ انتخاب در مرورگر
- رادار نمادها و انتخاب نماد از کارت یا نوار نمودار
- نمودار تعاملی کندلی/خطی بر پایهٔ **TradingView Lightweight Charts 5.2.1**، با بزرگ‌نمایی، جابه‌جایی، Crosshair، OHLC و سطوح قیمت
- نمایش حجم فقط زمانی که مقادیر واقعی حجم در رکورد داده باشند؛ حجم تخمینی ایجاد نمی‌شود
- جزئیات سناریوها: منطق، تریگر، تأیید، ابطال، ورود، حد ضرر، اهداف و مدیریت
- نقشهٔ چندتایم‌فریمی، سطح‌ها، ناحیه‌ها، نقدینگی و سویپ
- مدیریت ریسک، چک‌لیست قابل‌ذخیره، تقویم، سشن‌ها و پیوند منابع
- ژورنال یادداشت‌های شخصی با ذخیرهٔ محلی مرورگر
- جست‌وجوی سریع با Ctrl/Cmd + K، خروجی چاپی/PDF و manifest نصب وب‌اپ
- فرایند استقرار خودکار GitHub Pages از طریق GitHub Actions

## اجرا و انتشار

### روی کامپیوتر برای آزمایش

فایل‌ها را clone یا دانلود کن و با یک وب‌سرور محلی ساده باز کن. برای مثال در پوشهٔ پروژه:

~~~bash
python -m http.server 8080
~~~

سپس http://localhost:8080 را باز کن. بهتر است صفحه را مستقیماً با file:// اجرا نکنی.

### GitHub Pages

1. مخزن armanemp/plan را باز کن و به **Settings → Pages** برو.
2. در قسمت **Build and deployment**، گزینهٔ **Source: GitHub Actions** را انتخاب کن.
3. پس از push روی main، workflow موجود در .github/workflows/pages.yml فایل‌های استاتیک را منتشر می‌کند.
4. نتیجه و URL نهایی را در **Actions** و سپس بخش **Pages** بررسی کن.

### هاست معمولی / cPanel

محتویات سایت را بدون پوشهٔ مخفی .git در ریشهٔ سایت، معمولاً public_html، بارگذاری کن. ساختار نسبی را حفظ کن؛ به‌ویژه این فایل‌ها/پوشه‌ها باید کنار index.html باقی بمانند:

- assets/
- data/plans.js
- docs/
- manifest.webmanifest
- NOTICE

سایت از مسیر نسبی استفاده می‌کند و برای دامنهٔ سفارشی به بازنویسی مسیرهای asset احتیاج ندارد. برای نصب‌پذیری وب‌اپ و استفاده از APIهای امن مرورگر، HTTPS را فعال کن.

## وابستگی‌های آنلاین

- **Vazirmatn** و **Inter** از Google Fonts برای تایپوگرافی فارسی/لاتین
- **TradingView Lightweight Charts 5.2.1** از unpkg برای نمودار
- هیچ framework یا build system اجباری ندارد؛ JavaScript برنامه به‌صورت مستقیم در مرورگر اجرا می‌شود.

دسترسی به CDN و Google Fonts برای بارگذاری نسخهٔ آنلاین به اتصال اینترنت نیاز دارد. اگر CDN مسدود باشد، چارت پیام قابل‌فهم خطا می‌دهد و فونت‌ها به فونت‌های جایگزین برمی‌گردند.

## افزودن پلن روز جدید

ساختار داده در data/plans.js تعریف شده است. برای حفظ آرشیو، رکورد جدید را به آرایهٔ plans اضافه کن؛ رکوردهای گذشته را بازنویسی نکن. مشخصات فیلدها و قواعد اعتبارسنجی در [قرارداد داده](docs/DAILY-PLAN-SPEC.md) است.

قواعد مهم:

- فقط OHLC، سطح، رویداد و منبعی را درج کن که واقعاً بررسی شده باشد.
- زمان ثبت، منطقهٔ زمانی و منبع را کنار داده نگه دار.
- وضعیت پلن را تا زمان مشخص‌شدن تریگر، ابطال، ریسک حساب، اسپرد و هزینه‌های واقعی روی draft نگه دار.
- دادهٔ D1 یا قیمت بسته‌شدن تاریخی را به‌عنوان قیمت زنده نمایش نده.
- اگر حجم بازار در منبع موجود نیست، volume: null بماند؛ سامانه آن را حدس نمی‌زند.

## مرزهای فعلی محصول

این نسخه **فرانت‌اند استاتیک** است. برای نسخهٔ نمایشی و انتشار عمومی یک سایت تحلیل و پلن مناسب است، اما به‌تنهایی سامانهٔ چندکاربره یا سرویس اشتراکی امن نیست:

- احراز هویت، اشتراک پولی، پرداخت، نقش‌های کاربری و محتوای مخصوص مشترکین در آن پیاده‌سازی نشده است.
- پلن‌های داخل data/plans.js در مرورگر هر بازدیدکننده قابل‌دسترسی‌اند؛ اطلاعات خصوصی یا داده‌ای که باید پشت دیوار اشتراک باشد را اینجا قرار نده.
- یادداشت‌های ژورنال و وضعیت چک‌لیست در localStorage همین دستگاه ذخیره می‌شوند و بین کاربران یا دستگاه‌ها همگام نمی‌شوند.
- دریافت قیمت زنده، تقویم به‌روز، حساب کاربری و ذخیره‌سازی ابری به backend و منابع دادهٔ مجاز و مشخص نیاز دارند. کلید API محرمانه را داخل HTML/JS عمومی قرار نده.

قبل از فروش اشتراک، این مرزها باید با backend، احراز هویت واقعی، کنترل دسترسی سمت سرور، سیاست حریم خصوصی، شرایط استفاده و سازوکار مانیتورینگ پوشش داده شوند.

## مجوز و انتساب نمودار

PLAN از TradingView Lightweight Charts استفاده می‌کند. پیوند و نشان انتساب در نمودار و پاورقی حفظ شده و متن NOTICE در فایل ریشهٔ مخزن موجود است. مجوز کتابخانه و شرایط توزیع را از [مخزن رسمی Lightweight Charts](https://github.com/tradingview/lightweight-charts) بررسی کن.

## کنترل فنی

پیش از انتشار نهایی، این موارد را روی مرورگر واقعی بررسی کن: نمایش در عرض 320px و دسکتاپ بزرگ، بارگذاری موفق CDN، انتخاب نماد/پلن، تعامل نمودار، چاپ/PDF، ذخیرهٔ محلی ژورنال، مجوزهای Pages و گواهی HTTPS. معتبر بودن نحو JavaScript به‌تنهایی جای تست مرورگر و بررسی منابع زنده را نمی‌گیرد.
